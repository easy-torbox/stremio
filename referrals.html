How it works

When a beginner clicks the setup page signup button, EasyTorbox can hand off one active community referral link to Torbox.

Stats count EasyTorbox handoffs only. This site cannot observe external Torbox registrations, purchases, or bonus awards.

Duplicate active codes are rejected. Accepted codes remain active until the backend expiry returned by the API.

Privacy: this contributor page uses Cloudflare Worker, D1, and Turnstile to reduce spam and rotate referrals. It does not collect Torbox API keys.
